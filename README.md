The Gym Management System is a web-based application built with PHP and MySQL to streamline gym operations. It allows admins to manage customers, training plans, diets, exercises, and fees, while users can explore gym equipment, training types, and diet plans, as well as provide feedback.

Features

Admin

Manage customer details (registration, joining dates, gender-based fees)

Track training programs and exercises

Maintain diet plans

View and update customer fees

Manage user feedback

User

Register and log in

View available training types and gym equipment

Explore diet plans and exercise routines

Provide feedback on gym services

Technology Stack

Backend: PHP (Core PHP or Laravel)

Database: MySQL

Frontend: HTML, CSS, JavaScript (Bootstrap for UI)

Server: Apache (XAMPP/LAMP/WAMP)

System Requirements

Hardware:

Multi-core processor

4GB RAM or more

Stable internet connection

Software:

Apache Server (XAMPP/WAMP/LAMP)

PHP 7+

MySQL Database

Web Browser

Modules

User Management - Registration, Login, Profile Update

Training & Exercise Management - View training types & exercises

Diet Plan Management - Access diet plans based on training goals

Fee Management - Display fees based on gender & training type

Feedback System - Users can submit feedback

Security & Testing

User authentication and role-based access

SQL Injection & XSS prevention

Data validation & error handling
